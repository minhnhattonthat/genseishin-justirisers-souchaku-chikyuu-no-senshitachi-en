# Style reference

One row per voice, with the lines that fix it. Binding for translators, reviewers and the phase 9 story pass; the
glossary's rulings and tables still win where they differ. Each event exists in three copies (one per chosen hero), so
a voice must sound the same in all three: check the sibling copy before changing one.

| Voice | JP markers | English register | Never |
|---|---|---|---|
| **Glen / Shota** | おれ, 〜ぜ, 〜ねえ, ッ‼ | Hot-blooded, blunt, impatient. Contractions, "gonna", "creeps", short exclamations. | Polite or measured phrasing; "we must". |
| **Gant / Naoya** | おれ, 〜だ, 〜ぞ, 〜せん, 〜う (volitional) | Calm strategist who reins Shota in. Complete sentences, firm, no slang, few contractions in orders. | "gonna", slang, panicking. |
| **Kageri / Yuka** | あたし, 〜わよ, 〜わ, 直也さん | Bright, brave, a little teasing. "Come on!", "Leave it to me!". Calls Gant "Naoya-san". | Cutesy baby talk; a plain "Naoya". |
| **Doctor Zora** | 我々, kanji-heavy, フフフ / ハハハ | Grand, smug, theatrical mastermind. "Fufufu...", "All goes according to our plan". | Panic (except his retreats, which stay arrogant). |
| **Zauras** | きさま, 〜てやる, ハハハ | Brutish, roaring threats. | Cleverness. |
| **Revived Zauras** (stage 5) | all katakana, broken (ココカラ サキ ニハ イカセン) | Broken, halting, ALL CAPS with ellipses: "NONE... SHALL PASS... BEYOND...!" | Normal sentence case. |
| **Gildoros** | ギギーッ, われわれ, 〜さん | Monster general; screeches "Gigiii!", boastful, barks orders at Zakoul. | Dropping the "Gigiii!". |
| **Gardias** | ククク, わたし | Cold, gloating manipulator. "Kukuku...". | Shouting without the sneer. |
| **Armor Gunner** | おまえたち, 〜てやる | Swaggering soldier, military bravado ("fireworks", "your grave"). | |
| **???** (heroes before the reveal) | the hero's own voice | Same voice as the hero who speaks, without giving the name away. | |
| **Narration** (s07, chapter ends) | だ/である, past tense | Storybook voice-over, past tense, a little grand. | Modern slang. |
| **System text** (save, menus, goals) | | Short, plain, imperative ("Defeat the Bugscenes"). | Flavour words. |
