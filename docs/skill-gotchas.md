# Skill gotchas

One line per gotcha: the reference file it belongs in, then the fact.

- references/setup.md: `fetch_emu.py gba-bios` got HTTP 404 from retrobios (2026-11-14); copied a BIOS with the expected SHA-1 300c20df... from a sibling project instead.
- SKILL.md Step 0: the plugin guard hook was not loaded; after adding the `hooks` block to `.claude/settings.json` it took effect within the same session, and it blocks any command containing the canary text, even inside an echo.
- references/emulator-qa.md: Mesen GBA `cpu.r0`..`cpu.r15` are the register keys in `emu.getState()`; `tools/lua/execregs.lua` logs them at an exec address.
- context-mode plugin truncates Bash/Read output over ~4 KB in this environment; print disassembly in ~30-line slices.
- references/graphics.md §Survey: a static sweep can run a game's own custom decompressor under unicorn (`tools/res.py` `Decomp`): exact output with no reimplementation; use `UC_ARM_REG_PC` (not register number 15) to check the return.
- references/emulator-qa.md §Visual QA: in an Orca worker with no subagents, `codex exec --sandbox read-only -i p1.png -i p2.png ... - < prompt.txt` reviewed 29 sweep pages in three background batches.
- references/graphics.md §Survey: GBA BG tilesets can carry a per-tile palette table between palette and tiles (this game: ntiles bytes, padded); a VRAM dump + vramfind.py found the true tile start when every coherence heuristic failed. Render whole screens (map + tileset), not linear tile dumps: Codex read linear BG dumps as 'fragmented' and full screens cleanly.
- scripts/sheet.py: mixed-size images (240x160 next to 240x480) get shrunk to ~70 px wide tiles even with --div 1; send such images to reviewers individually instead.
- Claude Code: an rm with a relative glob after cd is refused by a built-in safety check; write to a fresh output directory instead of clearing one.
- references/emulator-qa.md §Debug tool: for a GBA game with a scene state machine, the fastest warp finder was the main loop: it called a dispatcher indexing a handler table by one RAM byte; poking scene/sub at the dispatcher's entry (L.on_exec) warped cleanly, and a static scan of BL calls to the goto/call helpers (`tools/scenecalls.py`) listed every transition.
- references/emulator-qa.md §emu.py: `--mash` also presses during the boot, so a warp script that waits for a menu gets knocked off it; mash from inside the warp script after the jump instead. A warp's own Start presses must stop before the jump frame: a Start still held when gameplay starts pauses it.
- references/emulator-qa.md §emu.py: Mesen randomises save memory, so the same cold-boot warp run reaches later screens a few hundred frames earlier or later between runs; give scene-list entries slack and test screen conditions, not frames.
- references/emulator-qa.md §Hooks: Mesen GBA Lua has emu.readWord/emu.writeWord (16-bit), not read16/write16.
- references/emulator-qa.md §Hooks: correction to the line above: in this repo's Mesen 2.2.1, GBA Lua `emu.read16`/`emu.read32`/`emu.write32` (addr, memType) do work (sub-81 probe and warp.lua unstick read real values).
- scripts/sheet.py: `--out DIR/sheet.png` fails with FileNotFoundError when DIR doesn't exist; mkdir it first (or the script should create it).
- references/emulator-qa.md §Debug tool: "reaches its scene" (scene byte check) is not proof. 13 of 93 entries passed warp_all's check but showed garbage, a hang, the wrong menu or a cursor that never moved; only reading every entry's sheet (codex exec, read-only) caught them. Also, entries poking past the game's last area (here areas 6-7) "reach" scenes the game never does: check where the game itself goes after the last area before listing more.
- references/emulator-qa.md §Visual QA: a `codex exec` reviewer judges each sheet against the entry description, so a wrong description reads as an issue (9 of 31 here: a carousel menu listed as three items, a CLEAR! banner that boss stages never show). Also, `--every 60` shots can miss a ~30-frame banner: re-run with `--every 20` before calling it missing.
- references/pipeline.md §Extract / scripts/tbl.py: with 2-byte glyphs on lead bytes (here 0x01-0x0B), a cell missing from the table decodes as `[01]` and the next byte is then read as a control code (`[01]{msg:...}`), which breaks the encode. Give every unnamed 2-byte code a generated fallback token (`{cXXX}`) before the table is complete. Also split messages token-aware: a 0x1F end code can be an argument byte (`13 1F 00`) or a glyph's low byte (`01 1F`); splitting on every 0x1F made 3 fake messages here.
- references/pipeline.md §Recon item 4: template-matching against MS Gothic got ~0% of kana and kanji right on this bold 2-px-stroke 16x16 font. Reading a zoomed cell sheet (fontsheet.py --zoom 4) beside each kanji's script context was quick: 61 kanji in one pass.
- references/platform-gba.md: a game's renderer can copy its text canvas to VRAM in whole tiles keyed to the old pen x and skip advances <= 7 px; with a VWF, glyphs lose tile columns (right halves missing). Hook the copy to align x down to its tile. Also check for 4bpp pair-packing bugs at odd x (keep widths even if the game's are).
- references/emulator-qa.md: a full 75-scene warp tour at --jobs 3 was killed by Claude Code's low-memory reaper while other agents' emulators ran; use --jobs 2 on shared machines and make tours resumable by scene list.
- references/emulator-qa.md §emu.py: the battery save persists in an emu.py --out run folder between runs, so a save-slot scene goes differently on its first run (empty slot: saves at once) and later ones (overwrite prompt). Clear or pin the .sav when a measurement depends on the slot state.
- references/pipeline.md §Width gate: a ruler line longer than the box can also break the *next* box (here a 9-line ruler in one prompt left the following prompt blank), and a renderer that character-wraps at the edge hides overflow as a silent mid-word wrap. Measure with rulers 1-2 glyphs over the limit, not whole-screen overflows; read the limit from ink columns per row (a 30-line helper, tools/inkrows.py here) rather than by eye.
- references/pipeline.md §Checks / scripts/jp_left.py: the string scan assumes NUL terminators; a game ending messages with another byte (here 0x1F) needs a per-message decode of the built text block instead (tools/romcheck.py `jp left`).
- references/pipeline.md §Checks: the stale-reader scan with flag bits masked (`w & 0x0E000000 == 0x08000000`, 2-aligned) on a 16 MB GBA ROM gave 10 false hits in graphics data; adding 0x0A-0x0D mirrors with flags gave 26 more, so allow flags only on bank 0x08 and allowlist the remaining data hits with a reason.
- references/graphics.md §Lettering: a BG redraw that adds tiles can overrun the next layer in VRAM (GBA: tileset copied as one run, another layer right after it, 0 slack here); a static render and a glance at one screenshot passed it, a cold-boot compare with the original showed a dot grid and a missing background. Measure the room from a VRAM dump before redrawing and make the build refuse a tileset past it.
- references/emulator-qa.md §Visual QA: an Orca worker cannot dispatch reviewer subagents; `codex exec --sandbox read-only -i SHEET.png ...` with the visual-QA brief works as the read-only reviewer (repo `tools/qa_codex.py` turns its reply into qa_gate verdict files). Codex flags deliberate vocative/exclamation line breaks as one-word last lines: add that standing non-bug to the brief.
references/graphics.md: GBA BG redraws can have 0 spare VRAM tiles (the tileset is copied as one run and the next layer follows at once); proportional English makes every cell a new tile while kana on a 16 px pitch share tiles. Lettering each glyph in its own 8 px cell (repo `bgtext.py` align g) lets repeated letters share tiles: config 383 -> 326 tiles, within budget.
references/graphics.md: map entries past the end of a tileset can show leftover VRAM that no resource holds (a button corner); once the English changes what else loads there, the cell turns black or garbage. Encode such cells as real tiles (here: copied from the left neighbour) instead of trusting VRAM.
