# Genseishin Justirisers: Souchaku Chikyuu no Senshitachi (GBA) English translation

Skill: translate-retro-game (Claude Code: plugin, enabled in .claude/settings.json; other agents: `<SKILL_DIR>/SKILL.md`; `$SKILL` = the directory holding its SKILL.md, printed by `python tools/skill.py`). Read it before ROM, text or QA work.

## Commands (run from repo root)
- Build:    `python -X utf8 build.py` -> build/justirisers_en.gba (checks the dump against `rom.sha1` first; English font + `en` text, block relocated to 0xD23570; every build runs `tools/romcheck.py` (write log `build/writes.txt`, allowed ranges `tbl/allowed.txt`) and stops on any error; `--verify` also requires the no-edit identity build to equal the dump; `--marker` -> build/justirisers_marker.gba with `[id]` markers; `--qa ID=TEXT` overrides one message for stress tests)
- Check:    `python -X utf8 tools/check.py` (unittest suite in `tests/` + lint; the pre-commit hook runs it). Hooks: `git config core.hooksPath tools/hooks` once per clone.
- Smoke:    `python -X utf8 $SKILL/scripts/emu.py build/justirisers_en.gba --out work/qa/smoke --route tools/routes/boot.txt --smoke`
- Warp:     `python -X utf8 $SKILL/scripts/emu.py build/justirisers_en.gba --out work/qa/warp --script tools/debug/warp.lua --var "SCENE='<name>'" --frames 900 --sheet` (scenes: `tools/debug/scenes.gba.txt`, generated by `tools/debug/gen_scenes.py`, frame budget in its last column; `--var GOD=1`; all/glob in parallel + regen `work/states/`: `python -X utf8 tools/debug/warp_all.py ["stage_*"] [--states]`; notes `docs/re/scenes.md`; never ask the user to play to a scene)
- Release:  `python -X utf8 tools/release.py` (patch + verify; never publish without the user)
- Clean:    `python -X utf8 tools/clean.py` (published projects: lists rebuildable/downloadable files; `--yes` deletes)

## Paths
- Original ROM: `rom/Genseishin Justirisers - Souchaku Chikyuu no Senshitachi (Japan).gba` (gitignored; SHA-1 in `rom.sha1`, checked by `tools/check_rom.py`); `work/orig.gba` is a space-free copy for emulator runs. Emulator: this repo's own MesenCE in `tools/mesen/` (MesenCE QA fork qa-1, `python $SKILL/scripts/fetch_emu.py mesen --dest tools --force`; upstream 2.2.1 held ~1.1 GB per run under Lua and ran the machine out of memory on tours; gitignored; BIOS `tools/mesen/Firmware/gba_bios.bin`, SHA-1 300c20df...; settings in `tools/emu-config/`). Savestates: `work/states/`.
- Text: `script/` (TSV, one per sub-table; `python -X utf8 tools/script.py dump|check|find ROM`, dump never overwrites without `--force` and keeps `en`). Tables: `tbl/`. Glossary: `glossary.md`. RE notes index: `docs/re/README.md`. Fonts and their licences: `docs/fonts.md`.

## Rulings
- Edit source files (.py .lua .asm .tbl .json) only with the file-edit tool; scripts here read and analyse, never `.replace()` and write back.
- Subagents: dispatch the agent types (translator, reviewer, visual-qa, playtester, graphics) shipped by the plugin as `translate-retro-game:<type>` (Claude Code), `.codex/agents/` (Codex) or `.opencode/agents/` (opencode), never general-purpose: their short tool list cuts each agent's start-up context from ~43k to ~9k tokens.
- The user's decisions, with the options and reasons: `docs/decisions.md`. Read it before asking the user anything; add each new ruling there the same session.
- Player bug reports: GitHub issues (`gh issue list --label bug`). Copy the attached save into `work/states/`, reproduce in the emulator, fix, commit with `Fixes #N`, and update `docs/status.md`.
- Gotchas: Konami/series logos run ~700 frames before Start skips to the title; `tools/routes/boot.txt` ends on the mode-select screen. The guard hook in `.claude/settings.json` blocks any Bash command containing `sed -i`, even inside a quoted string.
